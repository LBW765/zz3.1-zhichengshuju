### 脚本要求

#### 1. 幂等性设计
迁移脚本必须支持重复执行，不会因为表/字段已存在而报错：

```javascript
// ✅ 正确：检查表是否存在
const tableExists = db.prepare(
  "SELECT name FROM sqlite_master WHERE type='table' AND name=?"
).get('table_name');

if (!tableExists) {
  db.exec(`CREATE TABLE table_name (...)`);
}

// ❌ 错误：直接创建，重复执行会报错
db.exec(`CREATE TABLE table_name (...)`);
```

#### 2. 事务保护
所有 DDL 和 DML 操作必须包裹在事务中：

```javascript
const db = require('better-sqlite3')(dbPath);

try {
  db.exec('BEGIN TRANSACTION');
  
  // 迁移操作
  
  db.exec('COMMIT');
  console.log('✅ 迁移成功');
} catch (error) {
  db.exec('ROLLBACK');
  console.error('❌ 迁移失败，已回滚:', error.message);
  throw error;
} finally {
  db.close();
}
```

#### 3. 脚本模板

```javascript
const Database = require('better-sqlite3');
const path = require('path');

// 支持命令行传入数据库路径
const dbPath = process.argv[2] || path.join(__dirname, '../data.db');
const db = new Database(dbPath);

console.log(`📦 数据库路径: ${dbPath}`);
console.log('🚀 开始执行迁移: YYYYMMDD_description');

try {
  db.exec('BEGIN TRANSACTION');

  // 1. 检查表是否存在
  const tableExists = db.prepare(
    "SELECT name FROM sqlite_master WHERE type='table' AND name=?"
  ).get('your_table');

  if (tableExists) {
    console.log('⏭️  表已存在，跳过创建');
  } else {
    // 2. 创建表
    db.exec(`
      CREATE TABLE your_table (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        created_at DATETIME DEFAULT CURRENT_TIMESTAMP
      )
    `);
    console.log('✅ 创建表: your_table');

    // 3. 插入初始数据（可选）
    const insert = db.prepare('INSERT INTO your_table (...) VALUES (...)');
    insert.run(...);
    console.log('✅ 插入初始数据');
  }

  db.exec('COMMIT');
  console.log('✅ 迁移成功完成');
} catch (error) {
  db.exec('ROLLBACK');
  console.error('❌ 迁移失败，已回滚:', error.message);
  throw error;
} finally {
  db.close();
}
```

## 注意事项

### SQLite 特性限制
- 不支持 `ALTER TABLE DROP COLUMN`（需要重建表）
- 不支持 `ALTER TABLE MODIFY COLUMN`（需要重建表）
- 添加 `NOT NULL` 列必须提供 `DEFAULT` 值

### 重建表示例
```javascript
// 1. 创建新表
db.exec(`CREATE TABLE new_table (...)`);

// 2. 复制数据
db.exec(`INSERT INTO new_table SELECT ... FROM old_table`);

// 3. 删除旧表
db.exec(`DROP TABLE old_table`);

// 4. 重命名新表
db.exec(`ALTER TABLE new_table RENAME TO old_table`);
```

### 回滚策略
- 保留数据库备份：`cp app.db app.db.backup.YYYYMMDD`
- 编写回滚脚本（如果需要）
- 记录迁移前后的表结构对比
