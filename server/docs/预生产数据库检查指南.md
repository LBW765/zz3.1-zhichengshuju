# 预生产数据库结构检查指南

## 方式一：直接在服务器执行 SQL（推荐）

SSH 登录服务器后执行：

```bash
# 1. 检查所有表
sqlite3 /home/ubuntu/zhizhen-data/app.db "SELECT name FROM sqlite_master WHERE type='table' AND name NOT LIKE 'sqlite_%' ORDER BY name;"

# 2. 检查编码规则表是否存在
sqlite3 /home/ubuntu/zhizhen-data/app.db "SELECT name FROM sqlite_master WHERE type='table' AND name IN ('code_rules', 'code_rule_segments', 'code_sequences');"

# 3. 检查 customers 表结构
sqlite3 /home/ubuntu/zhizhen-data/app.db "PRAGMA table_info(customers);"

# 4. 检查编码规则数据
sqlite3 /home/ubuntu/zhizhen-data/app.db "SELECT code, name, enabled FROM code_rules;"
```

## 方式二：使用检查脚本

```bash
# 1. 上传检查脚本到服务器
scp server/check-db-structure.js ubuntu@129.204.62.13:/home/ubuntu/zhizhen3.1/server/

# 2. SSH 登录服务器
ssh ubuntu@129.204.62.13

# 3. 执行检查脚本
cd /home/ubuntu/zhizhen3.1
node server/check-db-structure.js /home/ubuntu/zhizhen-data/app.db
```

## 本地数据库结构（参考）

### 所有表（16 张）

- code_rules
- code_sequences

- departments
- menus
- permissions
- platform_config
- role_data_permissions
- role_menus
- role_permissions
- roles

- users

### 编码规则模块
- ✓ code_rules (4 条记录)
- ✓ code_rule_segments (12 条记录)
- ✓ code_sequences (0 条记录)

### customers 表结构
| 字段 | 类型 | 约束 |
|------|------|------|
| id | INTEGER | PRIMARY KEY |
| customer_no | TEXT | NOT NULL UNIQUE |
| name | TEXT | NOT NULL |
| contact_name | TEXT | NOT NULL |
| contact_phone | TEXT | NOT NULL |
| status | INTEGER | DEFAULT 1 |
| remark | TEXT | DEFAULT '' |
| created_by | INTEGER | NOT NULL |
| created_at | TEXT | DEFAULT datetime('now', 'localtime') |
| updated_at | TEXT | DEFAULT datetime('now', 'localtime') |

### 编码规则数据
| 业务标识 | 规则名称 | 状态 |
|---------|---------|------|
| customer | 客户编号 | 启用 |
| order | 订单编号 | 启用 |
| contract | 合同编号 | 启用 |
| product | 产品编号 | 启用 |

## 需要检查的关键点

1. **编码规则三张表是否存在**
   - code_rules
   - code_rule_segments
   - code_sequences

2. **customers 表是否有 customer_no 字段**
   - 字段类型：TEXT NOT NULL UNIQUE

3. **编码规则是否有预设数据**
   - 应该有 4 条规则（customer, order, contract, product）
