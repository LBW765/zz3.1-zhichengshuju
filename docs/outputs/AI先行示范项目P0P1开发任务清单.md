# AI 先行示范项目 P0/P1 开发任务清单

> 依据：`docs/outputs/AI先行示范项目核心功能对照表.md`
>
> 范围：仅纳入 P0（必须补齐）和 P1（业务深化）条目，共 175 项，其中 P0 95 项、P1 80 项。
>
> 使用方式：按阶段从上到下开发。任务包中的“覆盖条目”保留对照表原编号，开发、测试和验收时必须逐项回填状态。

## 1. 完成口径

### 1.1 任务完成的最低标准

每个任务包必须同时具备：

- 页面入口和角色可见性；
- 后端接口、参数校验和统一响应格式；
- 数据表或演示数据；
- 正常、空数据、错误、无权限状态；
- 状态流转和操作日志；
- 至少一条可复现的演示验收路径。

只增加目录卡片、静态文字或通用申请，不视为任务完成。

### 1.2 Demo 实现边界

- P0/P1 先采用可控的演示数据和模拟执行器，保证业务流程可以完整走通。
- 算力真实调度、模型托管、第三方检测机构、工业设备、支付和隐私计算属于 P2 外部接入，不放入本清单。
- 模拟执行器也必须记录申请、执行、结果、报告和日志，后续接入真实系统时保持接口不变。
- 角色至少覆盖公众、企业、服务商、运营、专家和政府；现有企业、运营、政府账号需要迁移到统一权限模型。

## 11. 端到端演示验收场景

以下 6 条场景必须在所有 P0 任务完成后走通，作为 Demo 的主验收路径：

| 场景 | 操作路径 | 关键角色 | 结果 |
| --- | --- | --- | --- |
| S-01 需求转项目 | 企业发布技术攻关需求 → 运营审核 → 智能匹配 → 人工撮合 → 服务商响应 → 转项目 → 里程碑 → 验收 → 案例 | 企业、服务商、运营 | 形成一条完整项目和成果记录。 |
| S-02 AI 资源申请 | 企业查看算力/模型/数据 → 提交申请 → 运营审批 → 模拟调用/下载 → 查看用量和日志 | 企业、运营 | 申请、授权、调用、用量和日志可追溯。 |
| S-03 智能体创建 | 企业选择模板 → 配置节点 → 测试运行 → 发布版本 → 查看运行记录 | 企业、服务商、运营 | 至少一个智能体可创建、运行和发布。 |
| S-04 中试验证 | 企业申请中试 → 配置指标 → 执行效果/安全/适配测试 → 整改 → 复测 → 生成报告 | 企业、专家、运营 | 有测试结果、整改记录和报告编号。 |
| S-05 赛事或揭榜 | 运营发布 → 企业报名/申报 → 资格审核 → 专家评分 → 公示 → 立项/成果转化 | 企业、专家、运营、政府 | 赛事或榜单至少一条完整闭环。 |
| S-06 资质和政府监管 | 企业申请认定/评测 → 材料初审 → 专家评审 → 证书/备案 → 政府看板下钻 → 风险处置 | 企业、专家、运营、政府 | 结果、备案、指标和风险互相关联。 |
