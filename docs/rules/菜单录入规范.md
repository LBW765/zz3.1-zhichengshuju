# 菜单录入规范

在“系统管理 → 菜单管理”录入新菜单时，按本规范填写字段。

## 字段速查

| 字段 | 规则 | 示例 |
| --- | --- | --- |
| 标题 `title` | 中文可读名称 | `用户管理` |
| 路由名 `name` | PascalCase，全局唯一 | `SystemUser` |
| 路由路径 `path` | 顶级带 `/`，子级不带 `/`，kebab-case | `/system`、`user` |
| 组件路径 `component` | 顶级菜单填 `Layout`，页面填 `views` 下相对路径 | `Layout`、`system/user/index` |
| 重定向 `redirect` | 顶级菜单建议填默认子页面 | `/system/user` |
| 图标 `icon` | Element Plus 图标名 | `Setting`、`User` |
| 布局 `layout` | 顶级菜单填 `sidebar` 或 `page`，子级留空 | `sidebar` |
| 平台 `platform` | `app-platform` 或 `admin-platform` | `app-platform` |
| 排序 `sort` | 数字越小越靠前 | `1` |
| 角色 `roles` | 可访问角色数组 | `["administrator","admin"]` |

## 当前基础菜单示例

顶级菜单：

```json
{
  "title": "系统管理",
  "name": "System",
  "path": "/system",
  "component": "Layout",
  "redirect": "/system/user",
  "icon": "Setting",
  "layout": "sidebar",
  "platform": "app-platform",
  "sort": 2,
  "roles": ["administrator", "admin"]
}
```

二级页面：

```json
{
  "parentId": 2,
  "title": "用户管理",
  "name": "User",
  "path": "user",
  "component": "system/user/index",
  "icon": "User",
  "layout": "",
  "platform": "app-platform",
  "sort": 1,
  "roles": ["administrator", "admin"]
}
```

## 组件路径

动态路由会从 `admin/src/views/**/*.vue` 中解析组件。

可用写法：

- `system/user`
- `system/user/index`
- `code-rule/list`
- `code-rule/list/index`

对应文件：

- `admin/src/views/system/user/index.vue`
- `admin/src/views/code-rule/list/index.vue`

## 权限码

权限码格式：`模块:资源:操作`

标准操作：

- `query`
- `get`
- `add`
- `edit`
- `delete`
- `export`
- `import`

示例：

- `system:user:query`
- `system:user:add`
- `system:role:edit`
- `system:menu:delete`

## 自查清单

- `name` 是否 PascalCase 且全局唯一
- `path` 层级是否正确
- `component` 是否能对应到真实文件
- 顶级菜单是否填写 `Layout`
- 顶级菜单是否填写 `redirect`
- 子级菜单 `layout` 是否留空
- `roles` 是否符合访问范围
