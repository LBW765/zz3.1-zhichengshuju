# 首次使用引导

欢迎使用多端管理模板脚手架。在开始开发业务项目前，请按以下步骤完成初始化配置。

## 第一步：菜单规划

菜单是后台管理系统的核心导航结构，直接影响用户体验和系统可维护性。

### 为什么要先规划菜单？

- 菜单结构决定了页面组织方式和路由设计
- 提前规划可以避免后期频繁调整导航结构
- 清晰的菜单分类有助于团队协作和代码组织

### 操作步骤

1. 打开 `docs/菜单规划.md` 文件
2. 根据你的业务场景，选择合适的菜单方案（通用型 or 简化型）
3. 填写 5 个顶级菜单的名称
4. 定义业务模块的归类规则

详细说明请参考 `docs/菜单规划.md` 中的指引。

## 第二步：数据库初始化

完成菜单规划后，启动后端服务会自动创建数据库并初始化预设数据。

```bash
# 安装后端依赖
cd server && npm install && cd ..

# 启动后端服务（首次启动会自动建表）
npm run dev:server
```

## 第三步：启动前端项目

```bash
# 安装后台管理端依赖
cd admin && npm install && cd ..

# 启动后台管理端
npm run dev:admin
```

访问 http://localhost:8131，使用预设账号登录：
- 账号：`administrator`
- 密码：`123456`

## 第四步：配置业务菜单

登录后台管理系统后，进入"菜单管理"页面，根据你在 `docs/菜单规划.md` 中的规划，逐步添加业务菜单。

### 菜单配置要点

- 顶级菜单：设置为"目录"类型，不需要配置组件路径
- 二级菜单：设置为"菜单"类型，配置对应的组件路径（如 `order/list`）
- 组件路径对应 `admin/src/views/` 下的目录结构

## 第五步：开发业务页面

根据菜单配置，在 `admin/src/views/` 下创建对应的页面组件。

示例：如果菜单配置的组件路径是 `order/list`，则创建：
```
admin/src/views/order/list/index.vue
```

页面开发规范请参考 `CLAUDE.md` 中的"前端页面规范"章节。

## 移动端开发（可选）

如果你的项目需要移动端，可以启动 uni-app 项目：

```bash
# 安装移动端依赖
cd app && npm install && cd ..

# 启动移动端 H5 开发环境
npm run dev:app
```

移动端开发规范请参考 `CLAUDE.md` 中的"app 端规范"章节。

## 常见问题

### Q: 菜单配置后页面显示 404？
A: 检查组件路径是否正确，确保 `admin/src/views/` 下存在对应的 `index.vue` 文件。

### Q: 如何修改顶级菜单数量？
A: 顶级菜单数量可以根据业务需要调整，不限于 5 个。但建议控制在 5-7 个以内，避免导航过于复杂。

### Q: 可以不做菜单规划直接开发吗？
A: 可以，但不推荐。提前规划可以避免后期大量重构工作。
