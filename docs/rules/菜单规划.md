# 菜单规划

> 本项目定位：**国家数字化转型平台**（工厂端，覆盖产品→生产→供应链→经营全链路）
> 报价表对应：`全软件模块标准报价表V4.5(1)(1).xlsx`

---

## 一、顶级菜单（已锁定，禁止新增）

### app-platform（业务平台，5 个上限）

| 序号 | 顶级菜单 | 定位 |
|------|---------|------|
| 1 | **工作台** | 跨模块聚合：首页、待办、消息、公告、BI 决策看板、协同办公（公文/审批/日程/网盘） |
| 2 | **产品与营销** | 商业前端：产品设计、工艺设计、营销管理、售后服务 |
| 3 | **生产运营** | 工厂车间：计划排程、生产管控、质量、设备、安全、能源 |
| 4 | **供应链与经营** | 物钱人合并：采购、仓储物流、财务、人力资源 |
| 5 | **系统管理** | 用户、角色、部门、菜单 + 字典、编码规则、条码、IOT 接入、传感器、视频通道、操作日志 |

### admin-platform（开发期工具，固定）

- 首页 / 平台配置 / 样式预览（其他超管维护功能）

## 二、二级菜单归类规则（必读）

新增任何业务模块前，按规则归位到对应顶级菜单下。**禁止新增顶级菜单**（系统已硬限制 5 个）。

| 业务特征 | 归属顶级 |
|---------|---------|
| 跨模块聚合、待办、消息、公告 | **工作台** |
| 决策看板 / BI 报表 / 数据可视化 | **工作台** |
| 公文、审批、日程、网盘、即时通讯 | **工作台** |
| 产品/工艺设计、BOM、设计文档 | **产品与营销** |
| 客户、销售、营销活动、订单（销售侧） | **产品与营销** |
| 售后工单、服务记录、客户回访 | **产品与营销** |
| 生产计划、排程、工单、排产 | **生产运营** |
| 工艺执行、生产监控、车间看板 | **生产运营** |
| 质量检验、质量监控、SPC、不合格品 | **生产运营** |
| 设备台账、点检、保养、故障、备件 | **生产运营** |
| 安全检查、隐患、事故、应急 | **生产运营** |
| 能耗监测、能源统计 | **生产运营** |
| 采购订单、供应商、采购对账 | **供应链与经营** |
| 仓库、库存、入库、出库、物流配送 | **供应链与经营** |
| 总账、应收、应付、账户、财务报表 | **供应链与经营** |
| 员工档案、考勤、薪资、组织架构（HR 维度） | **供应链与经营** |
| 用户/角色/部门/菜单/权限 | **系统管理** |
| 字典、编码规则、条码规则 | **系统管理** |
| IOT 设备接入、传感器、视频通道 | **系统管理** |
| 操作日志、登录日志、审计 | **系统管理** |

### 基础资料归类（重点）

基础资料按"维护权责"拆分，**不单独立顶级菜单**：

| 类型 | 示例 | 归属 |
|------|------|------|
| **业务主数据** | 客户档案、供应商档案、物料档案、仓库/库位、车间/工段/工位、产线、设备档案、员工档案 | 跟随对应业务模块（客户→产品与营销、供应商/物料/仓库→供应链与经营、车间/产线→生产运营、员工→人力资源） |
| **系统基础数据** | 数据字典、单位、币种、税率、枚举、编码规则、条码规则 | 系统管理 |
| **跨模块共享档案** | 组织架构、行政区划、节假日、汇率 | 系统管理 |

判断口诀：
- **业务人员每天用** → 跟业务模块走（就近原则）
- **IT 管理员维护、跨模块共享** → 进系统管理

> 不确定归类时，按"使用者角色"判断：
> - 销售/客户经理用 → 产品与营销
> - 车间主任/班组长/质检/设备员用 → 生产运营
> - 采购员/仓管/会计/HR 用 → 供应链与经营
> - 全员或管理层用 → 工作台
> - IT 管理员用 → 系统管理

## 三、协作执行规范

### 新增二级菜单的流程

1. **判断归类**：对照上面的"归类规则"确定挂在哪个顶级菜单下
2. **创建页面**：在 `admin/src/views/<模块名>/<页面>/index.vue` 创建页面
3. **菜单管理录入**：登录后台 → 系统管理 → 菜单管理 → 在对应顶级菜单下新增二级菜单（填名称、路径、组件路径，无需改 router 代码）
4. **后端接口**：在 `server/routes/` 新增模块路由，按 `server/CLAUDE.md` 的"新增接口步骤"执行
5. **同步文档**：如新增了公共组件、接口路径或目录结构，同步更新根目录 `CLAUDE.md`

### AI 协同开发规则

- 处理"新增模块"任务时，**必须先读本文件确认归属**，再开始动手
- 处理"新增功能"任务时，对照报价表 `全软件模块标准报价表V4.5(1)(1).xlsx` 的功能描述实现
- 涉及多个模块的功能，参考报价表的子模块拆分粒度
- 严禁未经确认就自行新增顶级菜单

### 模块归属冲突处理

如某个新模块同时符合多个归类规则（例如"销售订单的财务对账"既属于营销也属于财务）：
- 优先归属"主要使用者"所在的顶级菜单
- 必要时在两个顶级菜单下都建入口（同一个组件，菜单管理用"发布到其他位置"功能）
